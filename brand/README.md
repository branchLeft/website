# Brand source assets

`branchLeft-logo.png` and `branchLeft-wordmark.png` are the source files the
derived assets in `public/` (`og-image.png`, `favicon-*.png`,
`apple-touch-icon.png`) were generated from. They're kept here for
reference/archival purposes only — nothing in the app reads from this
directory, and there's no regeneration script; if these ever need
regenerating, redo it by hand from these sources.
