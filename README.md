# branchLeft — website

The branchLeft marketing / product website, built with React Router v7 (SSR) + Tailwind CSS v4 + Sass.

## Stack

- **Framework:** React 19 + React Router v7 (SSR, framework mode)
- **Styling:** Tailwind CSS v4 · Sass (SCSS) · self-hosted fonts
- **Build:** Vite 8 · pnpm
- **Tests:** Vitest
